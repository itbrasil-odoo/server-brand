By default the option is enabled, so no additional configuration is
needed. To show the Odoo promotional link again, go to Settings \>
Technical \> User Interface \> Views (developer mode), search for
*Remove Odoo Promotional Link* and archive it; unarchive it to hide the
link again.

When the module is installed with tests enabled (`--test-enable`), the
view is installed archived so that other modules' tests see the standard
footer; unarchive it on such databases.
